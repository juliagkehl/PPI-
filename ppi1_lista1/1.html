Diferença entre Internet e Web 🤯

A Internet é a base global de redes conectadas que permite a troca de dados entre os dispositivos,
enquanto a Web é um serviço que funciona sobre a Internet, onde permite acessar sites e páginas por navegadores.

História da Internet e da Web!

A história da Internet começou a partir de projetos de comunicação entre computadores. Um dos principais acontecimentos foi a criação da ARPANET, uma rede criada nos Estados Unidos no final da década de 1960.

A ARPANET utilizava a ideia de troca de pacotes para transmitir as informações, e, com o passar dos anos
novas redes foram surgindo e os protocolos de comunicação foram evoluindo.

Os principais marcos da Internet

  1. 1969: criação da ARPANET.
  2. 1971: envio de um dos primeiros e-mails.
  3. 1983: adoção do protocolo TCP/IP pela ARPANET.
  4. 1989: Tim Berners-Lee propõe a World Wide Web.
  5. 1991: a Web é disponibilizada publicamente.
  6. 1993: o navegador Mosaic ajuda a popularizar a Web.
  7. 1994: criação do W3C para padronizar a Web.

Tim Berners-Lee foi o criador da World Wide Web em 1989. A primeira versão da Web utilizava conceitos como HTML, HTTP e URL.

HTML
Linguagem de marcação utilizada para criar a estrutura de páginas Web.
URL
Endereço utilizado para localizar um recurso na Web.
HTTP
Protocolo utilizado para comunicação entre clientes e servidores Web.

Um dos símbolos associados à história da Web é o computador utilizado nos primeiros projetos relacionados à World Wide Web.

A evolução da Web

No início, a Web era formada principalmente por páginas simples de texto e links. Com o tempo, passou a oferecer imagens, vídeos, aplicações interativas e diversos serviços utilizados diariamente.

Atualmente, a Web permite acessar informações, estudar, trabalhar, conversar e utilizar diferentes serviços. A evolução dos dispositivos e das redes também contribuiu para aumentar o acesso à Internet.
