Sobre git

Sobre git discutimos o funcionamento do git, o que é o workcopy, stage, commit, repositório. Os comandos git utilizados são listados abaixo 🦥​

  • git init | cria um respositório git vazio .git
  • git status | exibe o estado do repositório
  • git add | adiciona no stage
  • git commit -m "mensagem" | faz um commit
  • git log | lista os commits da branch (ramo) atual
  • git config user.name "Julia Kehl"
  • git config user.email "kehljulia08@gmail.com"
  • git remote add origin url
  • git checkout branch | recupera wk apartir de um branch
  • git push origin main
  • git clone https://github.com/juliagkehl/PPI-.git
